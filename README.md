# The Power of Giving — Sunstone Class

Bilingual family community service website for the 2026–2027 school year.

Open index.html, or download The-Power-of-Giving-Offline-Kit.zip and extract it, then open START-HERE.html. The kit includes both original school flyers. Use Export backup to keep family data safe. Family notes are stored only in the browser, never uploaded to GitHub.

GitHub Pages serves the main branch root.
